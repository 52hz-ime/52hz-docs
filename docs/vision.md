# 项目愿景

## 一句话定义

52Hz 是一个以大语言模型为核心、能够从设备相关噪声输入中恢复用户意图的自然语言输入系统。

## 背景

传统输入法通常要求用户遵循相对固定的拼音、词典和选词流程。用户需要尽量准确地输入，系统再从有限候选中完成映射。

52Hz 采用相反的方向：用户可以按照自己的习惯输入，系统负责理解输入中的上下文、设备特征和错误模式，并尽可能直接完成表达。

## 核心体验

用户可以输入：

- 连续而不分词的拼音
- 长句
- 中文、英文、数字和符号混排
- 键盘相邻键误触后的字符
- 漏按、多按和局部字符交换
- 用户长期形成的非标准输入习惯

系统的目标不是把每个字符纠正成标准形式，而是从整段输入中推断用户最可能想表达的内容。

## 设计原则

### 系统适应用户

用户不应该为了适应输入法而改变自然的输入方式。

### 意图优先

原始输入是带噪声的观测信号，最终目标是恢复表达意图。

### 设备是上下文

键盘布局、设备形态、触摸方式和个人错误习惯都会影响输入的含义。

### 一次成功优先

目标是 99% 的日常输入能整段打完、按一次空格就得到想要的文字，不用看候选或回头修改。候选框只在用户主动要求修改，或结合上下文和个人记忆仍有实质歧义时出现。具体行为和验收口径见[产品定义](product-definition.md)。

### 可控和可逆

系统自动完成的内容必须可以撤销、修改或重新选择，不能把模型推断当作不可逆事实。

### 本地优先

基础输入能力尽可能在本地完成。云端模型是可选增强能力，不能成为基础输入的必要依赖。

## 非目标

当前阶段不以以下目标为优先：

- 从零训练通用基础大模型
- 一开始支持所有桌面和移动平台
- 让 LLM 参与每一次按键的全部处理
- 通过云端服务替代本地输入核心
- 用复杂的候选列表掩盖模型不确定性
