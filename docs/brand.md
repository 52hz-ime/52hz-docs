# 品牌方向

## 名称

项目名称：**52Hz**

灵感来自“52 赫兹鲸鱼”的故事。这个故事常被描述为一只使用不同频率发声的鲸鱼。科学上不能简单断言它一定孤独，但它提供了一个有力的产品隐喻：不同频率不代表无法沟通，只是需要有人愿意调谐。

## 核心文案

首选口号：

> 输入不必同频，表达依然抵达。

备选文案：

- 每一种输入，都值得被听见。
- 不必输入得完美，也能表达得准确。
- 让系统适应你的输入频率。

## 视觉意象

核心 mascot 是一只鲸鱼，结合以下元素：

- 尾巴和声波
- 水柱和文字流
- 拼音、英文和符号混排
- 键盘按键或光标
- 不同频率的波纹

整体气质应当友好、聪明和有探索感，不把鲸鱼塑造成悲伤或孤独的形象。

## 品牌原则

- 不把错误输入表现成用户犯错。
- 不使用过度技术化的视觉语言作为唯一表达。
- 让鲸鱼既能代表倾听，也能代表跨距离沟通。
- 保持轻量、亲近、可动画化的卡通形象。
