# 路线图

## Phase 0：定义问题

- 确定产品愿景和核心术语
- 建立真实输入样例集
- 定义设备错误模型的初始范围
- 记录可重复的产品评测方法

## Phase 1：Linux 原型

- 支持 Linux 桌面
- 接入 Fcitx5
- 建立输入会话和组合态
- 支持拼音、英文和符号混排
- 验证连续输入和低置信度交互

## Phase 2：设备感知解码

- 建立 QWERTY 键盘邻接图
- 加入替换、漏失、重复和转置模型
- 支持 DeviceProfile
- 建立合成噪声数据生成器
- 对比规则模型和 LLM 模型

## Phase 3：本地模型和个性化

- 评估本地小模型和量化 LLM
- 建立模型 Provider 接口
- 支持用户词汇和个人错误模式
- 完成本地优先的隐私策略
- 建立准确率、延迟和资源占用基准

## Phase 4：产品化 Linux 版本

- 覆盖 X11 和 Wayland
- 测试 GNOME、KDE、浏览器、编辑器和终端
- 完善安装、更新、诊断和撤销体验
- 发布第一个可供真实用户试用的版本

## Phase 5：其他平台和云端增强

- Windows TSF 适配
- macOS InputMethodKit 适配
- 可选的云端整句增强
- 模型发布和配置同步
- 移动端输入方式研究
