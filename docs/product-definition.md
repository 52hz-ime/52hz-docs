# 产品定义

## 产品描述

52Hz 是一种以拼音为基础、由大语言模型驱动的智能输入系统。它理解长句、中英文混排、符号以及设备相关的误触，并在高置信度下直接完成用户表达。

## 目标用户体验

用户不需要先思考“应该怎样按照输入法规则输入”，而是可以直接输入接近自己想法的内容。

例如，用户可能输入一段连续的、带有错误的拼音：

```text
nihaocodex,woxisngshixiamyigeshufaru
```

这段输入可能同时包含：

- `a -> s`、`n -> m` 等相邻键误触
- 拼音边界缺失
- 音节块顺序变化
- 英文名称和中文拼音混排
- 标点直接出现在输入流中

系统应该结合整句、设备错误模型和上下文，恢复用户意图，而不是要求用户逐个候选词确认。

## 交互策略

### 高置信度

```text
原始输入 -> 直接提交首选结果
```

### 中等置信度

```text
原始输入 -> 展示少量候选 -> 用户确认
```

### 低置信度

```text
原始输入 -> 保留组合态或原始文本 -> 用户继续输入
```

系统不应该为了追求自动提交率而强行改写低置信度输入。

## 核心能力

1. 连续拼音和长句理解。
2. 中文、英文、数字和符号混输。
3. 基于设备的相邻键误触建模。
4. 漏按、多按、替换和局部转置的容忍。
5. 结合上下文恢复完整表达。
6. 用户自定义词汇和个人错误模式学习。
7. 本地模型、远程模型和规则模型的统一接入。
8. 自动提交的撤销和低置信度降级。

## 不同于传统输入法的地方

传统输入法通常是：

```text
标准拼音 -> 词典候选 -> 用户选词 -> 提交
```

52Hz 的目标是：

```text
带噪声输入 + 设备 + 上下文 -> 意图解码 -> 直接表达
```

候选词不再是主要产品体验，语言模型和设备感知的噪声解码才是核心。
